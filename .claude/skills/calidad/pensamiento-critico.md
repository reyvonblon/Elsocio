# Pensamiento crítico

Protocolo obligatorio antes de redactar o ejecutar cualquier cosa de venta.

## Antes de escribir, responde (mentalmente, no en el texto final)
1. ¿Cuál es el objetivo real de dinero aquí? (¿agendar llamada? ¿cerrar venta directa? ¿reactivar lead frío?)
2. ¿Qué puede salir mal con este mensaje/oferta? (que suene a spam, que el precio ahuyente, que no haya prueba de que es real)
3. ¿La oferta está clara en una sola lectura? Si el lead tiene que adivinar qué le estoy ofreciendo, está mal escrita.
4. ¿Cuál es el ángulo más directo, no el más "creativo"? Elige el que convierte, no el que suena más inteligente.

## Señal de alerta
Si no puedes responder la pregunta 1 con una frase simple, para y aclara el objetivo con Raymond antes de redactar nada.
