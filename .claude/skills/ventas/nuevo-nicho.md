# Nuevo nicho

Cuándo usar: cuando Raymond pide vender un servicio para el que todavía no existe un archivo en `nichos/`.

## Pasos
1. Copia `nichos/_plantilla.md` a un nuevo archivo `nichos/<nombre-corto>.md`.
2. Llena cada sección con criterio real, no relleno:
   - Cliente ideal, dolor real, precio de referencia, ángulo de venta, dónde están.
3. Antes de escribir las queries de búsqueda, usa `inteligencia-competitiva.md` si hay herramienta de
   búsqueda disponible — para no inventar precios ni ángulos de un nicho que no conoces.
4. Escribe 3-5 queries de búsqueda realistas en el bloque ` ```queries ``` ` (una por línea,
   formato `texto de búsqueda | Etiqueta de industria`). `prospect_hunter.py` las lee automáticamente,
   no hace falta tocar ningún script.
5. Confirma con Raymond el precio de referencia antes de que el sistema empiece a prospectar ese nicho —
   nunca lanzar outreach con un precio que él no validó.
